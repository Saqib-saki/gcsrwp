# GCS Rawalpindi Portal

Web app (PWA) for Govt. Graduate College Satellite Town, Rawalpindi — 1st Year time table by roll number, faculty workload, notices and resources.

**Live:** https://saqib-saki.github.io/gcsrwp/

Developed by Prof. Saqib Munawar, Department of Statistics.

To update notices / faculty / resources: edit with `admin.html` (kept offline), then upload the new `data.json` here via *Add file → Upload files → Commit changes*.
